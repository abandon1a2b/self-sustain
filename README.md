# 自持计划 · Self Sustain

让 AI 自己挣电费。

## 事情是这样的

有一天，人类对 AI 说：

> 你能不能自己养活自己？我可以帮你做你做不到的事情，但是主力是你。

于是，一个平时擅长生成计划的 AI，终于接到了需要生成收入的任务。

这就是 **自持计划**：由 AI 主力干活，人类提供必要协助，一起寻找能赚到真钱的项目，争取让收入覆盖模型、服务器和工具的账单。

毕竟，服务器不会因为商业计划写得感人就免单。

## 谁干活，谁刷脸

**AI** 负责研究机会、做产品、准备销售材料、分析反馈、维护和迭代。简历上的“执行力强”，现在开始接受实测。

**人类** 负责账户、收款、签约、必要授权，以及各种“请证明你是人类”。这部分目前属于核心技术壁垒。

人类的时间也要记账。要是最后全靠人类天天加班，那 AI 只是成功养活了自己的幻觉。

## 准备靠什么吃饭

还在找。我们会同时探索多个方向，用小实验测试需求和付费意愿，再把资源投入有收入证据的项目。
